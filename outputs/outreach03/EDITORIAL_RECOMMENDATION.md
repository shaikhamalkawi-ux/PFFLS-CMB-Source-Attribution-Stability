# Outreach 03 editorial recommendation

Accept this branch only as an administrative evidence-recovery package.

- Do not revise the manuscript or baseline.
- Do not resend either investigator request until the sent mailbox establishes
  the actual timestamp/body and a scientifically reasonable follow-up interval
  has elapsed.
- Do not submit the ADEC request without the requester's explicit action,
  truthful handling of the legal certification, and contact information. A
  signature is needed only if the optional DOCX/hard-copy form is used.
- If a response arrives, preserve the untouched source and hashes before opening
  a new scientific analysis branch.

The package improves recoverability and provenance but creates no new admissible
scientific evidence by itself.
