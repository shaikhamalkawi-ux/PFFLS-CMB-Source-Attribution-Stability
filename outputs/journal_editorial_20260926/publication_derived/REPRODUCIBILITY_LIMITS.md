# Reproducibility limits and canonical objects not present in this release

The following canonical machine-readable objects are not present in the current publication-derived reproducibility release:

1. The prior complete editable/executable source tree used for the original source-native runs.
2. The canonical unrounded 30-comparison JRC machine-output ledger.
3. The row-level canonical EPA whole-profile substitution ledger underlying the 323 / 283 / 26 subsets.
4. The complete prior source-native executable reproducibility archive.
5. The canonical JRC INTERCOMP2 a priori sample-level source-contribution reference series (364 daily samples across the reference source categories).
6. The separate source-profile workbook identified in the archived scientific record by SHA-256 `699c04cf1479b882b0b7cd523ba1e79fe1b1c1f6956cd67d8a6043cd111503ed` has not been newly re-acquired in the present release workspace.

A newly acquired official `RM_INTERCOMP2_PACKAGE.zip` has been identity-checked. It confirms the 364-day/38-species synthetic participant dataset and known-source-contribution design, but it does not distribute the daily a priori reference SCE series. `EXAMPLE_INTERCOMP2.xlsx` is not treated as that reference object.

No row-level reference values were invented to fill these gaps. The release preserves the reported numerical results, provides a transparent reconstruction of the lower-mean-reduced-chi-square 30-comparison table from displayed 12-set values, and labels that reconstruction explicitly. Before a permanent repository deposit is described as the canonical source-native computational archive, the prior archived bytes should be restored or equivalently regenerated from official inputs and verified against the reported outputs.
