# Reproducibility scope

This archive reproduces and verifies the derived tables reported in the manuscript used to check the manuscript's headline values. It is intentionally labeled **publication-derived** because the prior complete source-native executable archive is not available in the present release workspace.

Run:

```bash
python code/reproduce_publication_derived_data.py
python code/verify_release.py
```

The official JRC INTERCOMP2 participant package acquired by the author is not redistributed here. Its SHA-256 identities and provenance boundary are recorded in `SOURCE_ACQUISITION_AND_PROVENANCE.md`.

The canonical 364-day a priori reference source-contribution series remains unrecovered and is not reconstructed.
