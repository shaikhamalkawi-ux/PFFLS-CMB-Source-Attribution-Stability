# Decision-certificate research: primary-source novelty audit

Date: 2026-09-26. Status: research triage, not a manuscript claim or exhaustive systematic review.

## Verdict

**The proposed move from profile-choice instability to ensemble-consensus partial orders, set-valued largest-source outputs, and abstention is scientifically useful but is not, by itself, a major new method.** There is direct prior art for the mathematical construction, substantial prior art for CMB/PMF uncertainty and ensemble outputs, and prior art for choosing measurements to distinguish models. A recent source-apportionment preprint creates additional priority pressure. A defensible next study must deliver a sharper CMB-specific result and validate it against these alternatives.

The current native EPA reconstruction is an unusually useful reproducible test bed. It establishes that the frozen historical numerical experiment can be independently reconstructed, including 133/283 pairwise-order changes and 62/283 largest-source changes among the declared two-diagnostic comparisons. It does not supply source truth, a representative profile uncertainty distribution, or statistical coverage. This distinction comes from the local `outputs/strengthening_20260926/README.md` and `EPA_NATIVE_RECONSTRUCTION.md`.

## What the proposed construction can honestly certify

Let `H` be an explicitly enumerated nonempty set of eligible, converged, accepted fits. Each fit has a source contribution vector `s(h)` in a common, predeclared source taxonomy. Define

`L_jk = min_{h in H} [s_j(h) - s_k(h)]`.

Then `L_jk > delta` certifies that source `j` exceeds source `k` by more than a declared margin `delta >= 0` in every member of **that set**. A strictly positive margin can account for known numerical error if error bounds are propagated conservatively. This is an exact finite calculation, not a new statistical theorem. Top-source candidates are the union of each member's argmax, including ties. A singleton gives ensemble-unanimous leadership; multiple candidates require a set-valued output if unanimity is the reporting rule.

Important limits for this repository:

1. The current historical experiment makes one profile substitution at a time. Agreement within its central-plus-alternative ensemble does not establish agreement over simultaneous substitutions, other source categories, continuous profile variation, or all physically possible profiles.
2. An accepted point estimate for each profile choice is not the same object as every contribution vector compatible with receptor error and profile uncertainty. A rank reversal may exist within one model's joint uncertainty region even when all point estimates agree.
3. Fit-screen thresholds do not create a confidence region automatically. The word *identified* requires a declared forward model, admissible parameter set and data-compatibility condition; *confidence* additionally requires a justified probability/coverage argument.
4. Unresolved numerical fits cannot safely be removed and then treated as evidence of unanimity over the original scenario list. Report ensemble incompleteness and distinguish algorithmic failure from scientific incompatibility. An empty accepted set gives a failed adequacy check, not a universal certificate.
5. Negative alternative estimates and sources removed by the central fit need explicit treatment. Historical signed EVLS reproduction, physical nonnegative feasible sets and new constrained fits are different experiments.
6. Marginal source intervals and joint pairwise contrasts are not interchangeable. Sources may be correlated. Compare against a joint covariance/posterior baseline before claiming new information over uncertainty reporting.
7. Alternative counts are not probabilities. Duplication of a profile should not change a worst-case certificate. Majority votes or equally weighted means require a separate interpretation.

## A narrower research direction worth attempting

The potentially stronger question is: **Which source-priority decisions are supportable under a declared joint uncertainty set, and what is the cheapest additional chemical information guaranteed to resolve a particular unresolved decision?** This is a candidate research question, not a verified novel contribution.

Define the admissible state as `(profile scenario, receptor error, profile uncertainty, contribution vector)`. Derive or compute lower bounds for specific source contrasts over that entire state set. Preserve dependencies among profile components and common systematic errors; independent rectangular perturbations should be labeled a sensitivity model unless externally justified. Report computable witnesses for ambiguity: two admissible states fitting the observations yet implying different leaders. These make the claim refutable and allow direct comparison with native CMB estimability diagnostics.

For candidate tracer `q`, each admissible state predicts a measurement interval after assay uncertainty is added. Optimize **decision resolution**, rather than profile identification in general: states with different source leaders matter; two states with the same leader need not be separated. A strong result would provide both (a) a constructive tracer or tracer panel with an explicit conditional guarantee and (b) an impossibility witness when all available measurements leave opposite decisions observationally compatible. Finding a best subset by brute force for a tiny candidate list remains an application; methodological novelty would require a nontrivial guarantee, tractable solver, or new domain-specific result.

There is a basic obstacle to a uniform assay guarantee. If the admissible states contain a continuous path crossing a source-leadership tie, and tracer predictions are continuous on that path, opposite leaders can yield arbitrarily similar predictions near the crossing. Positive assay-error intervals then overlap. A uniform guarantee requires additional restrictions, such as a scientifically meaningful minimum leadership margin, or must permit unresolved outcomes. A positive separation among finitely many fitted scenario points does not settle this continuous-state question. This is a direct mathematical observation for the proposed design, not an asserted new theorem.

The major empirical contribution could instead be a well-controlled demonstration that standard diagnostic acceptance and common uncertainty summaries systematically overstate source-priority certainty, followed by independently validated recovery of reliable decisions through a small chemical panel. That needs truth-bearing mixtures or external evidence, a frozen procedure and meaningful baselines. The existing 35-sample EPA experiment can develop and debug this study but cannot alone provide environmental ground truth.

## Decisive falsification and go/no-go tests

| Test | Observation that defeats the stronger claim |
|---|---|
| Direct prior-art reduction | Proposed mathematics is exactly consensus minima over a finite ensemble, or a standard discriminating-design objective with renamed variables. Keep as an application/tool contribution; do not sell as a new framework. |
| Joint profile expansion | A claimed leader reverses under an allowed simultaneous substitution omitted by the one-at-a-time ensemble. Restrict or withdraw the certificate's stated scope. |
| Within-profile uncertainty | A feasible joint perturbation changes the leader inside a single profile choice. Point-fit consensus does not establish decision identification. |
| Native diagnostic comparison | EPA eligible-space/estimability outputs plus ordinary joint source-contrast intervals flag the same cases with the same informativeness. Added value must then be practical or empirical, not claimed as newly detecting ambiguity. |
| Missing-source / profile misspecification | Truth is outside the declared source/profile family and the method issues a confident wrong leader. A conditional mathematical guarantee may survive, but an unconditional field-reliability claim fails. Include an adequacy-failure output. |
| Honest selective performance | On independent known-truth mixtures, non-abstaining decisions are not more reliable at matched reporting rate than joint-covariance or Bayesian alternatives. The decision benefit is unsupported. Report risk versus reporting rate and set size, not accuracy alone. |
| Tracer baseline comparison | Decision-targeted selection does not outperform random panels, condition-number selection, or standard model-discrimination selection at equal assay cost and reporting rate. New selection value is unsupported. |
| Measurement realism | Predicted separation disappears with detection limits, correlated assay error, profile variability, or chemistry altering the marker. Ideal noiseless separation is insufficient. |
| Holdout leakage | Tracers are selected using the same receptor values later treated as new measurements, or selection thresholds use test truth. Redesign as predeclared masking/reveal experiments and label retrospective evaluation accurately. |
| External transfer | Gains disappear on independent source profiles, dates or sites. A benchmark-specific result may remain; a broadly applicable method claim does not. |
| Numerical certification | An adversarial feasible witness contradicts an asserted bound or optimization lacks a certified bound. Relabel numerical estimates as heuristic until validated. |
| Failure and emptiness audit | Dropping unconverged/adverse scenarios or an empty feasible set produces apparently stronger claims. This invalidates the reporting implementation. |

## Recommended decision at this stage

Proceed with finite-ensemble decision summaries as a diagnostic prototype and explicitly cite their established basis. Do not label that prototype a major scientific upgrade. The first scientific go/no-go gate is whether an enlarged, justified joint admissible set yields useful decision certificates beyond native CMB estimability and joint uncertainty baselines. The second is whether a frozen decision-targeted assay procedure improves reliable source decisions on truth-bearing or independently checked data. Failure at either gate is informative and should stop novelty escalation.
