# Bounded follow-up: stronger benchmark and reference-software gaps

Audit date: 2026-09-26 UTC. Three leads only. This is an additive discovery memo, not a new benchmark protocol, outcome analysis, or amendment of the completed experiments. No fitting, scoring, installation, code execution, or external write was performed. One openly licensed 7,526-byte software archive was read in memory to inspect its source; it was not saved or extracted to disk.

## Decision

**No additional fully qualified physical aerosol-mixture truth benchmark was verified in this bounded search.** Two useful software families and one particularly relevant released EVLS implementation were located. None supplies all of known source contributions, independent measured profiles, receptor errors, and empirically established profile-error covariance. This is a search outcome, not evidence that such a dataset does not exist.

The most actionable immediate result is a stronger *comparator audit*, not another performance claim: the released Dai–Hopke EVLS code accepts both receptor and profile standard deviations but still reports a plug-in inverse-normal-matrix covariance. The Bayesian package estimates profiles and contributions jointly, but changes the error model and identification assumptions. ESAT provides reproducible synthetic construction truth and uncertainty tools, but not independent physical validation. Each therefore needs a separate, preapproved fairness protocol before use.

## Prior routes deliberately not repeated

Read the existing `TRUTH_BENCHMARK_AUDIT.md`, `NOVELTY_AUDIT.md`, source ledgers, and prior candidate-admission evidence first. The Via release remains a construction-truth dataset without measured profile uncertainty; its completed experiment must not be retuned. Previously audited Barrow, APHH Beijing, and Chengdu material does not provide the complete independent CMB truth/input tuple. Historical Quail Roost II / Palookaville references did not previously yield exact machine files. JRC gated raw inputs, Fairbanks restricted inputs, correspondence, new terms, and paid-access routes were excluded. No absence-of-novelty or novelty conclusion is inferred from failed retrieval.

## 1. Dai and Hopke: released EVLS-CMB R reference implementation

**Verified artifact.** DAI, QILI and Hopke, Philip, *R code for EVLS-CMB source apportionment*, v1, 2025-11-30, [DOI 10.5281/zenodo.17767035](https://doi.org/10.5281/zenodo.17767035). The [record API](https://zenodo.org/api/records/17767035) independently identifies CC BY 4.0. Exact file: [EVLS_CMB_code.zip](https://zenodo.org/api/records/17767035/files/EVLS_CMB_code.zip/content), 7,526 bytes. Published MD5 and independently calculated in-memory MD5 agree: `120453456bb51d2d00d3a07a8ae12bf4`. The description's different illustrative ZIP name is not the released filename.

The [archive preview](https://zenodo.org/records/17767035/preview/EVLS_CMB_code.zip?include_deleted=0) confirms two R scripts and four CSVs for receptor means, receptor uncertainties, profiles, and profile uncertainties. The record explicitly calls these **templates to replace**, not the underlying Tianjin observations or a known-source mixture. Default dimensions are 18 species and eight named source categories. Units and empirical uncertainty provenance are not established by these templates.

**Independent source inspection, not execution.** `EVLS_CMB_core.R` iterates unconstrained WLS using diagonal effective variance

`v_j = sigma_C,j^2 + sum_k s_k^2 sigma_A,jk^2 + 1e-30`.

It returns source covariance `(A' W A)^-1`, evaluated using the final available iteration weights, and its diagonal square roots. It does not integrate over uncertain profiles, accept profile cross-covariances, or propagate a joint profile/contribution posterior. It does not enforce nonnegative coefficients, and it returns no explicit convergence-status flag after the iteration cap. These are implementation properties, not measured performance findings. A future adapter must report failures and preserve these distinctions rather than silently repair the method.

The associated [Chen et al. paper, DOI 10.1021/acsestair.5c00312](https://pubs.acs.org/doi/abs/10.1021/acsestair.5c00312), applies EVLS to PMF-derived profile uncertainty. Publisher abstract/metadata were read; full text was not obtained. The code is a worthwhile reproducible EVLS baseline and a direct challenge to simplistic novelty claims, **but does not meet the requested beyond-plug-in joint-uncertainty comparator by itself**. Article reuse rights are not inferred from the separate software license.

## 2. bayesMRM / BNFA: released joint Bayesian receptor-model software

The primary [2021 software paper, DOI 10.1016/j.chemolab.2021.104280](https://www.sciencedirect.com/science/article/pii/S0169743921000484), describes an R package and MATLAB implementation. The [CRAN distribution mirror](https://github.com/cran/bayesMRM) supplies inspectable original package files; it is not represented here as the authors' development repository. [DESCRIPTION](https://github.com/cran/bayesMRM/blob/master/DESCRIPTION) identifies version 2.4.0 (2022-12-14), GPL >= 2, R >= 4.0.0, and JAGS-related dependencies. The canonical CRAN pages could not be read with the web tool; the advertised source-tarball bytes were not independently retrieved.

In the released [bmrm function and model documentation](https://github.com/cran/bayesMRM/blob/master/R/bmrm.R), receptor data are modeled through jointly estimated nonnegative source contributions and profiles, with normal or Student-t residuals and an estimated diagonal residual variance. Profile priors distinguish near-zero structural entries from free entries; contribution priors include a covariance parameter. This is genuinely beyond conditioning on one fitted profile matrix. However, the interface does not supply an observation-by-species absolute uncertainty matrix or an empirical profile-entry covariance matrix. A scalar prior spread for free profile entries is not laboratory profile-error covariance.

The bundled [Elpaso documentation](https://github.com/cran/bayesMRM/blob/master/man/Elpaso.Rd) describes 224 complete observations of 15 PM2.5 species and a four-factor structural prior. It is a field illustration, **not independently known contributions**. The [package checksum list](https://github.com/cran/bayesMRM/blob/master/MD5) names `data/Elpaso.rda`; no RDA was downloaded or deserialized. Package metadata establishes code licensing, not an independently audited license chain for the original monitoring measurements.

**Potential value, conditional.** This is the strongest lead for a joint-profile inference comparator, provided a new protocol freezes its information advantage, structural zeros, source alignment, prior sensitivity, residual law, MCMC diagnostics, and endpoint normalization. Structural zeros or labels selected using test truth would invalidate the comparison. Posterior probabilities are not automatic frequentist calibration or empirical ground truth. The methods antecedent, [Park and Oh 2015, DOI 10.1016/j.chemolab.2015.08.021](https://doi.org/10.1016/j.chemolab.2015.08.021), further limits any novelty claim based merely on jointly uncertain profiles/contributions.

## 3. EPA ESAT: openly released simulator and PMF uncertainty tooling

The primary [JOSS software paper, DOI 10.21105/joss.07316](https://joss.theoj.org/papers/10.21105/joss.07316), and [EPA release metadata, DOI 10.23719/1531870](https://doi.org/10.23719/1531870), identify the Environmental Source Apportionment Toolkit. EPA links the exact [v2024.0.3-alpha archive](https://github.com/quanted/esat/archive/refs/tags/v2024.0.3-alpha.zip). Its [versioned source license](https://github.com/quanted/esat/blob/v2024.0.3-alpha/LICENSE) is Apache 2.0; the JOSS article independently declares CC BY 4.0. Archive bytes were not downloaded or hashed.

The exact-tag [simulator source](https://github.com/quanted/esat/blob/v2024.0.3-alpha/eval/simulator.py) constructs true profiles and contributions, their matrix product, added noise/outliers, and a reported uncertainty matrix. Its defaults generate noise and reported uncertainty separately. Nonpositive data and uncertainty entries are replaced by small positive constants. Consequently, the supplied uncertainty matrix cannot simply be assumed to equal the generating noise standard deviation, and default nominal-coverage claims would be unwarranted. The simulator's truth-based correlation ranking of fitted models must not select a winner in a blinded comparison. Its saved pickle should not be deserialized as untrusted input.

Current [maintainer documentation](https://quanted.github.io/esat/docs/modules.html) describes bootstrap, displacement, and combined uncertainty analyses, with [simulation documentation](https://quanted.github.io/esat/docs/eval.html). Those pages describe a newer release than the EPA-pinned tag; feature parity has not been exhaustively verified. This is reproducible **synthetic construction truth**, in arbitrary generated scales, not controlled physical mixture truth. There is no independently measured uncertain-profile covariance in the inspected generator.

**Potential value, conditional.** ESAT could supply an external generator and joint-factor perturbation comparator. It is an NMF/PMF model, not a drop-in known-profile CMB solver. A new protocol would need equal-information conditions, fixed factor-label matching, scale-invariant contribution endpoints, explicit noise/uncertainty agreement or misspecification, and identical risk/coverage denominators. Replacing one synthetic construction with another alone would not establish a major scientific advance.

## Stop rule and next-decision gates

The three-lead limit is reached. No scoring or additional artifact collection is authorized by this memo. The machine-readable ledger distinguishes inspected source, advertised archive, in-memory verified bytes, and unverified full text; no source availability is inferred from a citation alone.

If further work is approved, the highest-value narrow question is whether **joint profile/contribution uncertainty changes scientifically relevant abstention or ordering decisions under an equal-information, explicitly specified error model**, compared with both ordinary EVLS and the existing bounded compatibility construction. A fair test must retain all failures/all-rejected cases, include misspecification rather than favorable-only simulations, and preserve fixed truth/co-leader denominators. Neither software sophistication nor a more elaborate simulation guarantees useful separation or novelty.

The open quantitative gap remains: independent known-source aerosol contributions plus released receptor measurements, independently characterized profiles, and defensible measurement/profile error information. No new paper full-text request is necessary to establish the three artifact-availability conclusions above. Full text of the 2025 EVLS article would become useful only if a future protocol needs its precise DISP-to-standard-deviation conversion and assumptions; it cannot turn the released templates into independent truth.
