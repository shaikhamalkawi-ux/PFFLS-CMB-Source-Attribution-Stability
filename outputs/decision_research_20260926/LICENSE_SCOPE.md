# Candidate decision-research licence scope

This notice applies only to the new, author-created candidate materials listed
in the final `PUBLIC_RELEASE_MANIFEST.json` accompanying this review. It does
not license this entire repository, adjacent private files, or the contents of
an owner-only Drive return. A draft directory without that final manifest is
not a completed public release.

The project owner approved MIT for original code and CC BY 4.0 for
author-created data and documentation. Within the explicit manifest:

- New original manifest-listed Python implementations and tests (`.py`),
  including the saved-ledger verifier in this output directory, are offered
  under the MIT text in `LICENSE_CODE_MIT.txt`.
- New author-created research notes, protocols, aggregate results, review
  records and reproduction documentation under this output directory are
  offered under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Git attribute files are repository configuration, not experimental results.
  This notice does not change pre-existing licence terms for repository files.

For attribution, identify the PFFLS project contributors, the specific file or
candidate release, the repository URL, and its review commit. Retain the
file's source citations and any separate third-party notices. Changes should
be identified. No endorsement by the original data providers is implied.

## Exclusions and third-party rights

No new licence is asserted over EPA input archives or source profiles,
Fairbanks data or correspondence, private reconstructed matrices and
sample-level ledgers, publisher papers, institutional-library downloads,
external software, or other third-party material. Public accessibility alone
is not a redistribution licence. The licences of NumPy, SciPy, h5py and any
other dependency remain their respective authors' licences.

The Via et al. benchmark's attribution and source licence are recorded
separately in `truth_dataset_attribution.json`. The original dataset archive
is not distributed by this candidate public subset. No article fulltexts,
raw datasets, source-native JRC inputs, manuscript, or owner-return proof
matrices belong in the public release manifest.

Existing R3nR8, Zenodo and publication archives remain unchanged; their
previously recorded licence scopes and versions are not replaced by this
notice. Permission to read an owner-only research return is not blanket
permission to publish its contents.

Licensing does not assert scientific correctness, novelty, journal readiness,
data-use permission for omitted inputs, or that every historical saved result
can be reproduced from this public subset alone.
