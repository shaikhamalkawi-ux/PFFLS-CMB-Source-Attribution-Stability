# Definition of "paper complete"

Do not declare the paper complete until all of the following are true:

## Science
- all reported results reproducible;
- claim boundaries consistent with evidence;
- no unresolved mathematical/numerical contradiction;
- no unsupported external-validation wording;
- no known stronger public evidence left unaddressed if it materially changes the conclusion.

## Manuscript
- title/abstract/conclusion aligned;
- every symbol/equation defined at first use;
- tables/figures internally consistent;
- no stale internal version text;
- no accidental wording leakage;
- no material Main/Supplement duplication;
- references complete and correctly cited.

## Reproducibility
- code and tests pass;
- source/provenance register complete;
- SHA-256 manifests pass;
- public-vs-restricted data boundary documented;
- one-command or clear reproduction instructions exist.

## Submission
- journal target selected and scope checked;
- manuscript formatted for target;
- cover letter/highlights/data-code statement prepared;
- author metadata placeholders or supplied metadata handled;
- submission ZIP/source package clean;
- final QA report produced.
